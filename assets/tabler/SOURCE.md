# Icon sources

The ribbon includes icon shapes adapted from [Tabler Icons](https://github.com/tabler/tabler-icons), licensed under the MIT License. See [LICENSE](LICENSE).

The source SVG files and pre-rasterized 48×48 RGBA assets are kept together so that the shipped icon artwork can be inspected. Icons derived from Tabler were selected from `icons/outline/*.svg` and adjusted for display in this application.

Examples of adapted mappings include `arrow-back-up` → `undo`, `arrow-forward-up` → `redo`, `git-branch` → `child`, `square-plus` → `sibling`, `trash` → `delete`, `chevrons-up` → `fold`, `chevrons-down` → `unfold`, `align-box-left-top` → `align_branch`, `arrows-minimize` → `align_all`, `zoom-in-area` → `fit`, `focus-centered` → `focus`, `zoom-reset` → `actual`, `layout-grid` → `new_map`, `copy` → `group`, `layers-subtract` → `ungroup`, `palette` → `palette`, `file-plus` → `new_file`, `folder-open` → `open_file`, `device-floppy` → `save_file`, `text-plus` → `insert_text`, `braces` → `pure_json`, and `link` → `link`.

Other SVG icons include application-specific drawings and modifications. `diamond` and `orthogonal` were drawn for this application rather than copied from Tabler Icons.
